# ⏱️ Stopwatch and Timer Using Python

## 📌 Project Description
This project is a simple **Stopwatch and Countdown Timer application** developed using Python and Tkinter. It provides a graphical user interface (GUI) that allows users to measure elapsed time and set countdowns easily.

## ✨ Features
- **Stopwatch:** Start, stop, resume, and reset the stopwatch.
- **Countdown Timer:** Set custom minutes and seconds.
- **Real-Time Display:** View elapsed time and remaining time.
- **Timer Notification:** Displays a message when the countdown finishes.
- **Input Validation:** Handles invalid timer inputs.
- **User-Friendly Interface:** Simple and interactive GUI.

## 🛠️ Technologies Used
- Python
- Tkinter (GUI library)

## 🚀 How to Run the Project

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd Stopwatch_Timer
   ```

3. Run the Python file:
   ```bash
   python main.py
   ```

   If necessary, use:
   ```bash
   py main.py
   ```

4. The application window will open. Use the stopwatch or enter a duration in the countdown timer.

## 🕹️ How to Use

### Stopwatch
1. Click **Start** to begin counting.
2. Click **Stop** to pause.
3. Click **Start** again to resume.
4. Click **Reset** to return to zero.

### Countdown Timer
1. Enter the desired minutes and seconds.
2. Click **Start** to begin the countdown.
3. Click **Stop** to pause the countdown.
4. Click **Reset** to reset the timer using the entered duration.
5. When the countdown reaches zero, a notification appears.
